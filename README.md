## Техническое задание

Необходимо создать React-приложение, которое показывает погоду в городах, а также поддерживает поиск, смену фона в зависимости от условий и просмотр актуальных задач пользователя.

## API

Список API для использования(если представленные API не удовлетворяют каким-либо условиям задания, можно использовать любые другие открытые API для погоды):

- [openweather](https://openweathermap.org/current)
- [stormglass](https://docs.stormglass.io/#/)
- [openweather](https://home.openweathermap.org)

## Необходимый функционал:

- Автоопределение местоположения (геолокация браузера или IP‑сервис) и отображение погоды для текущего местоположения;
- Реализация поисковой строки для выбора города с использованием elastic search(вспомогательный список по совпадению), для получения городов можно использовать стороннюю API, также необходимо реализовать debounce с задержкой 1 секунда;
- Интеграция с погодным API (Weather API, StormGlass или любой другой открытый сервис);
- Отображение 24-х часовой погоды по геолокации или другому введённому городу;
- Слайдер для прокрутки погоды по дням c отображением ощущаемой температуры, шанса дождя, скорости ветра и ультрафиолетовым индексом. Также при переключении дня в слайдере должна обновляться и 24-х часовая погода;
- Адаптивная верстка (мобильные устройства, десктоп);
- Должна быть реализована возможность подгрузки событий из Google Календаря и отображения их на UI (как это представлено на дизайне). Для этого будет необходимо осуществить интеграцию с Google Календарём (например, посредством следующей библиотеки - react-google-calendar-api. При желании, можно использовать любую другую). Данный функционал подразумевает реализацию логики входа/выхода из аккаунта;
- Реализация иконок для отображения погоды;
- Смена фона и иконок в зависимости от погоды;
- Реализация страницы 404 Not Found;
- Реализация Loader для отображения запасного UI при подгрузке данных (Skeleton UI/Spin Loader);
- Кэширование запросов к погодным сервисам для уменьшения трафика и избегания блокировки на бесплатных API. Реализовать Redux + Redux persist для сохранения состояния между перезагрузками.

### Дополнительные указания

- Реализацию иконок для отображения погоды следует продумать самостоятельно;
- Реализация Loader для отображения запасного UI при подгрузке данных.

## Описание экрана

На странице пользователь может просмотреть 24-х часовую погоду по своему местоположению или ввести в поисковую строку любой другой город. Имеется возможность переключить день в слайдере и посмотреть погоду на выбранный день (обновится и погода на 24 часа). Также имеется возможность зайти/выйти из своего Google аккаунта и посмотреть актуальные события в календаре или бегущей строке.

### Также проект предполагает:

- Организацию файловой структуры react приложения. Ссылка на структуру: [Cтруктура проекта](https://github.com/mkrivel/structure);
- Деплой приложения на платформу GitHub Pages или иные другие (Netlify, ...);
- Настроить конфигурации **_babel_**, **_eslint_**, **_prettier_**, **_husky_**, **_commitlint_**;
- Использование TypeScript для типизирования и уменьшения количества потенциальных багов;
- Обработку ошибок через паттерн **_Error Boundaries_**;
- Использование алиасов для импортирования файлов;
- Также реализация общей темы для стилей в проекте - [ссылка на пример](https://habr.com/ru/articles/591381/);
- Оптимизацию дизайна под мобильные устройства;
- Покрытие тестами всего приложения (jest - 25% покрытия);
- Придерживаться принципов DRY, KISS, YAGNI.
- Обязательную анимацию при наведения, нажатии на кнопки, прокрутки карусели и слайдеров, появлении элементов на странице при рендере и скролле.

## Используемые технологии

### Для react

- **_node.js_** - программная платформа, основанная на движке V8 (транслирующем JavaScript в машинный код);
- **_yarn_** - менеджер пакетов;
- **_react_** - JavaScript-библиотека для создания пользовательских интерфейсов;
- **_redux_** - библиотека для работы с состоянием приложения;
- **_redux-persist_** - библиотека для кеширования данных в локальное хранилище;
- **_redux-saga_** - библиотека для создания асинхронных действий;
- **_styled-components_** - система стилизации react компонентов;
- **_react-hook-form_** - библиотека для работы с формами;
- **_jest_** — unit тестирование для веб-приложений;
- **_vite_** - сборщик для приложений;
- **_prettier_** - инструмент для форматирования кода;
- **_eslint_** - линтер для JavaScript кода;
- **_husky_** - современное решение для управления Git хуками;
- **_babel_** - транспайлер, преобразующий код из одного стандарта в другой;
- **_commitlint_** - инструмент, который проверяет сообщения commit-ов на соответствие общепринятым стандартам их описаний.
